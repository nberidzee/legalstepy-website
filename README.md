# LegalStepy Website

Bilingual marketing website for LegalStepy, an AI-powered contract lifecycle management platform.

## Preview locally

Open `index.html` in a browser or serve the repository with any static file server.

## Structure

- `index.html` — page structure and content
- `styles.css` — responsive design and animations
- `script.js` — language switching and interactions
- `assets/brand` — LegalStepy brand assets
- `assets/team` — founder portraits

## Languages

The website supports English and Georgian. The selected language is saved in the visitor's browser.
